# Сайт PLOMBIR: запуск и выкладка

Новая главная (`/` и `/en/`) собирается этим проектом. Всё остальное — `/phuket`, `/shop`, документы, будущие лендинги — продолжает жить в Tilda и открывается на том же домене через прокси.

```
plombir.events/          → этот проект (RU)
plombir.events/en/       → этот проект (EN)
plombir.events/phuket    → Tilda, адрес в браузере не меняется
plombir.events/<любой>   → Tilda, если такой страницы нет в проекте
```

Служебный адрес проекта в Tilda: `https://project4207141.tilda.ws`. Если он поменяется, его нужно заменить в `vercel.json`, `netlify.toml` и `deploy/nginx.conf`.

## Работа с проектом

Нужен Node.js 22.

```bash
npm install
npm run dev      # локально на http://localhost:4321
npm run build    # готовый сайт в папке dist/
```

- Тексты: `src/i18n/ru.ts` и `src/i18n/en.ts` (порядок элементов в массивах совпадает).
- События, релизы, артисты, контакты: `src/data/site.ts`.
- Картинки: исходники кладутся в `../src-assets`, затем `npm run images` создаёт сжатые версии в `public/img`.
- Яндекс Метрика: задать переменную `PUBLIC_YM_ID` (номер счётчика) в настройках хостинга.

## Выкладка

### Вариант 1. Vercel или Netlify
1. Загрузить проект в репозиторий на GitHub.
2. В Vercel (или Netlify) создать проект из этого репозитория. Настройки сборки уже лежат в `vercel.json` / `netlify.toml`.
3. После первой сборки открыть временный адрес (`*.vercel.app` / `*.netlify.app`) и пройти проверку ниже.
4. В настройках проекта на хостинге добавить домены `plombir.events` и `www.plombir.events`. Хостинг покажет, какие DNS-записи нужны.

### Вариант 2. Свой сервер
1. Собрать сайт (`npm run build`) и скопировать `dist/` на сервер.
2. Взять `deploy/nginx.conf`, указать путь к `dist/`, выпустить сертификат (например, certbot).

## Проверка до переключения домена
- [ ] Главная RU и EN, переключатель языка в шапке.
- [ ] `/phuket` открывается целиком: картинки, анимации, все блоки.
- [ ] Кнопки «Купить билет» на лендинге ведут в Qtickets.
- [ ] Формы Tilda отправляются, заявки приходят.
- [ ] `/shop`: корзина и оплата.
- [ ] Документы: `/offerta`, `/policy`, `/vozvratbileta` и остальные.

## Переключение домена
1. За сутки уменьшить TTL у DNS-записей домена до 300 секунд.
2. Поменять записи на те, что показал хостинг (обычно A-запись для `plombir.events` и CNAME для `www`).
3. Через 5–30 минут проверить сайт ещё раз по списку выше.
4. Подписку Tilda не отключать: она обслуживает лендинги и магазин.

## Перед запуском заменить
- Ссылки на билеты в `src/data/site.ts` (`upcoming[].tickets`): сейчас ведут на `/events` и `/phuket`. Лучше поставить прямые ссылки Qtickets.
- Проверить цифры и формулировки в текстах: «60+ релизов», «11 лет», почта для демо.
